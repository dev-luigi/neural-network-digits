# Code of conduct

This project is open to everyone. In issues, pull requests and every other space of the project:

- be respectful, also when you disagree;
- criticise the code and the ideas, not the people;
- no insults, harassment, discrimination or personal attacks;
- no offensive or sexual content;
- do not publish other people's private information.

If someone does not respect these rules, the maintainer can edit or delete their comments, close their
issues and pull requests, and block them from the project.

To report a problem privately, write to Luigi Tanzillo: dazzler-yip3o@icloud.com
